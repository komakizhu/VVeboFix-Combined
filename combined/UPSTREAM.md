# 合并版来源

微博接口模块来自 [nildeveloper/VVeboFix](https://github.com/nildeveloper/VVeboFix/blob/201d20697188de69d7e7557952ef02eee6158748/VVeboFix.m)，
固定提交为 `201d20697188de69d7e7557952ef02eee6158748`。
构建脚本只从上述固定提交地址获取该文件，不把上游源码副本放入公开仓库。
该上游仓库未提供独立 LICENSE 文件，本项目不为上游模块补造授权或声称拥有其代码。

构建时去除未使用的 UIKit 引入、关闭含请求地址的调试日志、标记未使用参数，
并将自动初始化入口移交统一加载器。原有 URL 改写、响应转换和 NSURLSession 注入逻辑沿用。
上游源码的全部 40 个字符串字面量都存在于用户提供的原 dylib 中；
这支持模块一致性，但不代表源码与原二进制逐指令等价。

已购模块使用仓库 `purchase_compat/` 中的 0.1.1 源码，保留 C 互斥锁修复，
由统一加载器调用，避免两个独立 constructor。合并版从源码重新编译，
不声称合并库的机器代码与先前已测试注入的原库逐字节相同。
